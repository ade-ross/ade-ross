## Featured projects

### [ft_transcendence](https://github.com/ade-ross/ft_transcendence): Clash of Olympus

A server-authoritative 3D browser fighting game with ELO matchmaking and real-time play over WebSockets. Four NestJS services and a React + Three.js client behind one NGINX gateway, built in a team of five.

- **My part:** the auth service: JWT access and refresh tokens, Google OAuth, email verification, password reset and TOTP 2FA.
- Contributed to the NGINX TLS and rate-limiting setup.

`TypeScript` `NestJS` `PostgreSQL` `Docker` `NGINX` `WebSockets`

### [ft_irc](https://github.com/ade-ross/ft_irc)

An IRC server in C++98 with no external libraries. One process with non-blocking sockets and a single `poll()` loop serves every client. It supports channels, operators and the five channel modes, plus a moderation bot. Built with a teammate.

`C++98` `sockets` `poll()`

### [cub3D](https://github.com/ade-ross/cub3D)

A Wolfenstein-style raycasting engine: textured walls, doors and real-time movement. Pair project.

`C` `MiniLibX`

### [Camagru](https://github.com/ade-ross/camagru)

A photo-sharing web app with no framework: my own router on Node's `http` module, PostgreSQL and Docker Compose. Webcam or upload, overlays composited on the server, likes, comments with email notifications, and infinite scroll.

`Node.js` `JavaScript` `PostgreSQL` `Docker`
